### C3：独立 scripted Agent、演示及整体检查点

- Agent 是独立进程，通过 DeviceClient 和受限 run token 使用同一 API，不直接访问 Runtime 数据库或仿真内部对象。

## 6. 必须覆盖的验收行为

按工程设计 §9 实现有效测试，以下特别容易出错，不能略过：

1. **整排与守恒**：A 排六孔同步更新、其他排/板不变；媒体减少量、废液增加量及吸头扣减正确；任一孔超限拒绝整个请求；取消/重试/恢复不重复提交。
2. **幂等与资源锁**：相同键重试只产生一次效果；同键不同规范化请求冲突；shake、扫描、移液之间按资源互斥。
3. **观测证据**：PNG 可解码、单/双目身份与冻结时刻正确、哈希可复现；换液后旧观测触发 observation_stale；不能拿场景截图或 oracle 真值伪装视觉证据。
4. **确定性**：同 seed、同脚本在 speed=1/600、加入随机 wall-time 决策延迟后，规范化动作序列、模拟状态/观测值和图片 hash 一致。随机实验 ID、壁钟时间等非语义元数据可排除比较，不能排除液量、模拟时间、事件因果顺序等核心字段。
5. **屏障**：终态与下一屏障同一模拟时刻且中间无推进；已有 lease 时立即成功的 set_targets 只追加 trigger、不换 lease；release 等待已终态动作时立即交出 next_lease；过期/他人 lease 拒绝；超时暂停并标记 determinism_broken。
6. **执行中 reset**：换液半程、shake、scan 分别重置；旧动作 experiment_reset 终结、旧世界之后不再变化、旧 token/迟到提交无效；新世界无 lease、无活跃 run，不自动推进，显式 step 可用。
7. **恢复**：响应丢失、Runtime 实际进程重启、Agent 实际进程重启、SSE 断线重连不重复执行或扣库存。至少关键恢复用例经过真实进程/HTTP 验证，而非只测试一个内存类。
8. **访问控制**：同源 cookie GET/HEAD 无 Origin 成功；cookie 写请求缺 Origin 拒绝；合法 Bearer 无 Origin 可用；跨源 Origin/非法 Host 拒绝；run token 不能 reset/control；一次性配对；LAN 无访问码拒绝启动；静态页面和资源不含令牌。GET 状态、SSE、图片也不能匿名越权读取。
9. **端到端**：三条演示驱动真实 Runtime → SSE → 3D/面板；刷新恢复、只读回放不写；关闭浏览器仍运行；Agent 不在时人工可操作；桌面和窄屏能完成主要流程。
10. **A 回归**：保留整排场景测试、资源映射校验和必要的浏览器验收。不能为了兼容旧单孔协议把排枪改回单针。

测试数据、数据库、令牌和生成资产用隔离目录，不污染用户演示数据；只清理自己创建的测试进程和临时数据。不得靠删测试、放宽断言、跳过认证或硬编码成功返回取得通过。
