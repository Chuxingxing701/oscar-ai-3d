# OSCAR–AI 三维展示模型 · V1

2026-09-29。基于用户五视图、内部全景、移液头特写、视频抽帧和新增正面实拍重建。用于路演视觉展示与后续动画制作，不是制造 CAD 或标定数字孪生。

## 打开预览

本机双击 `打开预览.cmd`，启动后浏览器打开 `http://127.0.0.1:8765/web/`。窗口关闭或按 Ctrl+C 即停止服务。Python 标准库即可运行，不需要 npm install 或联网加载。

也可以在本文件所在目录运行：

```powershell
python server.py
```

其他电脑若有 Node.js，也可以运行 `node server.mjs` 后在浏览器打开上述地址；此服务同样不需要安装依赖。

页面支持：拖动旋转、滚轮/双指缩放；点击设备或“进入工作舱”显示内部；返回外观；暂停/继续动画；复位、正面视角、自动旋转。拖动与点击分开识别，双指手势不触发切换。

手机/平板与电脑在同一可信局域网时，可显式开启局域网服务：

```powershell
python server.py --lan --port 8765
```

然后使用 `http://电脑的局域网IPv4:8765/web/`。是否能够连接取决于本机防火墙和网络隔离设置；本次没有修改系统防火墙，也未发布公网地址。正式路演可将整个文件夹部署至静态站点服务，保留 `web/` 与 `models/` 的相对路径。

## 尺寸、坐标与部件层级

- Blender：米；X 左右、Y 前后、Z 高度；正面朝负 Y，地面中心为基准。
- 柜体名义尺寸按用户估算的 2.1 × 0.6 × 1.8 m 建立。包含把手、按钮和面板小凸出后的外观包围盒约 **2.106 × 0.628 × 1.800 m**。这不是设备实测尺寸。
- GLB 导出器自动转为 Y 向上；网页看到的正面朝正 Z。不必额外旋转模型。
- `Exterior` 包含柜壳、门、窗、显示屏、装饰和下部可见组件；隐藏此组即可展示内部。
- `Interior` 包含主工作舱内壁、金属台面、20 个布局工位、托盘、孔板、枪头盒、管架、培养皿及固定承载结构。
- `Motion → Motion_X → Motion_Y → Motion_Z` 保留分轴层级。移液头黑色主体、金属针轴和橙色侧框在 `Motion_Z` 下；可单独编辑。
- `90_Studio` 仅用于 Blender 渲染，不导出到 GLB。
- 孔板建模使用 127.8 × 85.5 mm 的名义尺寸，工位底座 145 × 100 mm，保留合理尺度；台面高约 0.90 m 为估算值。材质及孔位是展示几何，不代表耗材具体型号。

## 已知简化和证据边界

1. **实拍优先**：下部中间柜门依据新正面实拍做为封闭门；早期产品渲染中的另一处瓶体观察窗没有照搬到此门上。
2. 内部布局根据实际全景重建主要相对位置；透视遮挡使部分工位与附件只能近似。没有逐一确认工位功能，部件清单使用位置编号。
3. 三维运动轴支架与后部导轨是为展示运动关系采用的简化结构；隐藏驱动系统、连接方式及行程未经实测。橙色框架保留形状但不模拟未经确认的开合动作。
4. 八根可见针轴是参考特写的视觉表达，**实际通道数未确认**。动画仅显示高位移动、定位、下降、停留和抬升；不展示实际吸液、出液或工艺效率。
5. 18 秒为设计的循环时长，不由剪辑视频推算。针尖最低位置仍保留展示间隙，不宣称完成孔内吸排操作。
6. 白色、金属与蓝色材质采用中性光重建，没有把监控画面的黄色偏色染入内部材质。观察玻璃使用近似半透明材质。
7. 品牌文字与装饰线为可替换的重绘近似；不等同品牌官方矢量文件。显示屏为标记了 `INTERFACE PLACEHOLDER` 的示意界面，**不是实际软件 UI**。低清小字没有补造为功能参数。
8. 第一版没有建立培养箱内部取放板机构、液体/软管仿真或完整实验流程；右侧柜体保留外观。
9. 原图最初可读取，建模过程中原微信临时路径已不可用。已保留此前生成的四图参考拼图；本包不声称包含原始照片全分辨率备份，原始视频也未复制进包。

## 后续修改

同事可直接打开 `.blend`，在集合中选中部件编辑。动画位于三个运动 Empty 的 NLA 轨道 `OSCAR_Demo_18s`，1–541 帧、30 fps。循环长度 18 秒。改变工位或行程后，先抬升再横移，并重新运行碰撞抽样检查。

程序化复现：

```powershell
# 使用已安装的 Blender；这里以原电脑路径为例
D:\blender\blender.exe --background --python source/build_model.py -- --skip-render
D:\blender\blender.exe --background --python source/validate_model.py
D:\blender\blender.exe --background --python source/render_views.py
```

重建使用包内现成 PNG，无需运行贴图脚本。若需重新生成贴图，使用带 Pillow 的 Python 执行 `source/make_textures.py`。

`parameters.json` 中的外包络项目前是估算基准记录，并不是所有几何的自动缩放开关。修改整机尺寸须同时调整脚本中的柜体、开窗和内部净空；不要整体非等比缩放孔板迁就柜体。台面高度读取 `deck_height`；动画关键帧和网页提示须随设计时长一起修改。

GLB 重导出时仅选择模型集合，不包含摄影棚。保持 `Exterior`、`Interior`、`Motion_X/Y/Z` 名称，网页依赖这些名称进行切换。页面在加载时按材质合并静态显示几何以减少绘制调用；分件完整性保留在原 GLB 和 `.blend` 内，运动部件不合并。

## 验证情况

- 三个 GLB 均检查了文件头、嵌入资源、部件节点和所需动画，并重新导入 Blender。
- 模型检查确认耗材位于台面范围内；每 3 帧抽样的移液头/耗材 AABB 检查未见穿插。此检查不是机械安全认证，也没有覆盖未知实物机构。
- 网页测试使用本机 Edge 自动化，包含 1440×1080 桌面视窗及 390×844 手机尺寸视窗；验证加载、点击/拖动区分、返回、暂停/继续与布局。具体结果见 `reports/browser_checks.json`。
- 手机尺寸视窗是桌面模拟，**未在实体手机、平板、Safari 或 Android 浏览器实测**。不能将本次结果视为所有设备性能已通过。
- 尚无公开托管地址。当前本地服务只监听 127.0.0.1；需要跨设备访问时显式运行 `--lan` 或部署静态文件。
