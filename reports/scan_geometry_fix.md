# 扫描穿模与示意线修复（2026-09-30）

用户截图：plate-01 B1 扫描时，头部/橙色侧框与左壁相交；扫描锥覆盖范围和示意线不清楚。

## 修改

- 原相机位于头部右前侧。把镜头对准左侧第一列孔时，原计算把头部中心推到约 x=-0.987 m，而舱壁内侧为约 x=-0.976 m；此前“镜头中心对孔”的测试无法发现头部已穿墙。
- 相机改为位于头部左下侧，镜头中心 `[-0.070, 1.262, 0.040] m`，`state.js` 的位姿计算与 `model.js` 几何共用 `CAMERA_POSITION`。深度与高度同时调整，避免摄像头藏入主体、接近针轴或为了避侧壁又撞后方立柱。
- 六通道展示头的橙色侧框及安装螺栓各向内移 28 mm。原始侧框跨度即使在整排针轴对齐时也会与左壁相交。针轴、针距、板孔、液量与 Runtime 动作参数不变。
- 扫描锥底面半径由 35 mm 缩为 5.8 mm。新增蓝色中心线和孔内光斑；起点直接使用可见镜头下端面的世界变换，终点使用动作目标孔的坐标。中心线、光锥顶点和光斑共享端点，不再手工维护另一套镜头偏移。
- 扫描结束、取消、reset 时统一隐藏锥、线和光斑。未重建 GLB / Blender 母模型，改动仍为场景展示几何。

## 验证

- 类型检查通过。
- `node --test tests/web/scene-adapter.test.mjs web/scene/tests/scene.test.mjs`：24/24。
- 从真实 GLB 读取侧壁、背壁、两根支撑立柱包围盒。对两块板 48 孔的扫描定位/进入轨迹，以及 8 排移液的横移/下降/排液/抬升路径采样，逐个检查运动网格包围盒，没有交叠。
- 对全部 48 孔验证镜头实际下端面、光锥顶点、线起点一致；线终点/光锥底面中心/孔内光斑一致。
- `python3 source/prepare_scene_assets.py --check`：7 工位、48 培养孔、288 吸头位及原始 4 纹理保持一致。
- `node reports/scan_geometry_check.mjs`：使用独立临时 Runtime，经真实 API 执行 plate-01/B1 与 plate-02/A1 扫描并截图，页面异常和场景更新错误均为 0。未改用户正在操作的实验数据。
